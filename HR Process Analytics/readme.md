# HR Hiring Analytics Project

<p align="center"> <img src="HR Hiring Process Analytics-1.png" alt="HR Dashboard Logo" width="700"> </p>

## 📌 Project Overview
This project leverages Power BI and HR analytics to provide actionable insights into recruitment patterns, workforce demographics, and hiring efficiency. The analysis focuses on key metrics such as:

- 👥 **Gender distribution in hiring**
- 📊 **Departmental recruitment trends**
- ⏰ **Temporal hiring patterns (day, time, and month)**
- 💼 **Position tier distribution and salary analysis**

## 📁 Folder Structure
- **HR_Dashboard.pbix** - Power BI file containing interactive visualizations and dashboards.
- **HR_Dashboard.pdf** - Exported PDF version of the dashboard for quick reference.
- **HR_Data.xlsx** - Processed dataset with interview records, demographic details, and salary data.
- **GitHub Repository** - Full project repository with all files.

## 🚀 How to Use
1. Open **Hiring-Process-Analysist.xlsx**[] in Excel to explore interactive insights.
2. Use **HR_Dashboard.png**[] for a quick snapshot of findings and recommendations.
3. The **HR_Data.xlsx**[] file contains raw and cleaned data for further analysis.
